# ReverseLab · AI 逆向设计工作台

面向机械零部件逆向设计的浏览器交互 Demo，展示扫描数据、三维姿态校正、特征识别与工程图复核流程。

## 本地运行

在项目目录执行 `python -m http.server 4173 --bind 127.0.0.1`，然后打开 http://localhost:4173/ 。请通过 HTTP 服务访问，以加载三维资源。

## 演示功能

- 三维网格预览：X/Y/Z 旋转、鼠标拖拽、滚轮与按钮缩放。
- 扫描流程界面：扫描数据导入、姿态校正和主视图方向选择。
- 特征识别流程：显示平面、圆柱、孔位、倒角、圆角及人工复核提示。
- 工程图预览与 PDF 下载。

## 实现范围

三维显示与旋转基于 Three.js 和 STLLoader 实现。数据导入、AI 识别、自动对齐和工程图生成目前为前端流程演示；未连接扫描仪、Open3D、推理服务或 CAD 内核。识别置信度是预设演示数据，导入不会替换三维几何，工程图为独立预置资料，尚不支持生成 STEP。

## 目录

- `index.html`、`styles.css`、`app.js`：工作台页面、样式与交互。
- `assets/`：本地三维资源、工程图与 Three.js 运行时。
- `THIRD_PARTY_NOTICES.md`：第三方资源及许可说明。
